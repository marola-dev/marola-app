# API reference

Generated by `just api-docs` on every `main` push
([`api-docs.yml`](https://github.com/marola-dev/marola-app/blob/main/.github/workflows/api-docs.yml))
and force-pushed to this repo's `api-docs` branch, which docs.marola.dev mounts beside these
pages. The trees are HTML, not Markdown, so they sit beside the site rather than inside its
navigation — this page is the way in.

## Scala

One scaladoc tree per module of the `build.sbt` build. Each link goes to `marola.html`, not the
tree's `index.html`: scaladoc's landing page has one line in its body, `Packages: package marola`,
so linking it lands the reader on a stub.

- [`core`](api-docs/scala/core/marola.html) — the pure pipeline, the shared HTTP/JSON helpers, and the
  `LlmClient` / `VisionClient` / `SightingStore` traits.
- [`local`](api-docs/scala/local/marola.html) — the Ollama-backed implementations of those traits, and the
  local-file sighting store.
- [`cli`](api-docs/scala/cli/marola.html) — `Main`, `AppConfig`, and the MCP tool server.

## Python

- [marola-ml's fine-tune and scripts](https://docs.marola.dev/5-Repos/marola-ml/api-docs/python/)
  — pdoc, from marola-ml's own `api-docs` branch. These are commands, not a library: each one's
  module docstring is its usage.

!!! note "These links resolve on the published site, not on GitHub"
    The `api-docs/` trees live on the `api-docs` branch, not in `main`, so the three Scala links
    above 404 when this page is read on GitHub.
